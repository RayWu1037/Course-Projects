# CS 251 Project 1: Ciphers

This project implements encryption and decryption tools for both **Caesar ciphers** and **substitution ciphers** in C++. It provides functions to encode and decode messages, a menu-driven program for users to encrypt/decrypt text, and a comprehensive suite of tests.

## Key components
- **ciphers.cpp** – Implements Caesar and substitution cipher algorithms for encryption and decryption.
- **ciphers_main** – Console application that interacts with the user to perform encoding and decoding operations.
- **include/** and **build/** – Header files and build artifacts.
- **test_data/** – Input files used for testing.
- **tests/** – Unit tests verifying the correctness of the cipher implementations.

This project was completed for the University of Illinois Chicago course **CS 251: Data Structures**. It demonstrates understanding of character manipulation, file I/O, and simple encryption techniques.
