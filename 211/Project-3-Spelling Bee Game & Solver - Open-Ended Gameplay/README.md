# Project 3: Spelling Bee Game & Solver

This project implements a **Spelling Bee** game and solver in C. It features an open‑ended gameplay mode where players attempt to form words using a given set of letters, as well as solver programs that brute‑force or optimize the search for valid words using a dictionary. Profiling outputs (gprof) are included to compare different solver implementations. Developed for the CS 211 course.
